# デザインの基本方針と見本

このスキルは2つの層でできている。

| 層 | 置き場所 | 中身 | 変える人 |
|---|---|---|---|
| 基本方針 | このフォルダ直下の `*.md` | どの見本を使っても守る考え方（何を伝えるか、どう並べるか、どのグラフを選ぶか、色をどう使うか） | 人間（構築時） |
| 見本 | `references/<id>/` | 具体的な値（色、余白、文字の大きさ）と、手本にするスライドの作り。元資料（PDF など）もここに置く | 作り手が自由に差し替える |

いま使う見本は `active.yaml` の `reference` に書いてある。

## いつ、どれを読むか

| 段階 | 読むファイル |
|---|---|
| 骨子を作る（どのスライドを何枚、どの順で） | `principles.md`、`layout.md`、見本の `slide-style.md` の「スライドの種類」 |
| 図表を作る | `charts.md`、`colors.md`、見本の `palette.md`。迷ったら見本の元資料（`source.*`）の該当ページを開く |
| 仕上げの確認 | `checklist.md`、`accessibility.md` |

- 基本方針と見本が食い違うときは、基本方針を優先する。見本の値は、基本方針の範囲内で使う。
- 見本の元資料に載っている図・文章・ロゴは、スライドに転載しない。参考にするのは考え方と作り。

## 見本を差し替える

1. `references/<新しい id>/` を作り、`README.md`（出典・取得手順・利用条件）、`slide-style.md`、`palette.md` を `references/README.md` の形式で書く。元資料は `source.<拡張子>` で置く（git 管理外）。
2. `active.yaml` の `reference` を書き換える。
3. `html-build` の `theme.css` と `layout-catalog.md` を、新しい見本の値で見直す。

## 出典

基本方針は、デジタル庁「ダッシュボードデザインの実践ガイドブック」（2026年3月31日更新）https://digital.go.jp/resources/dashboard-guidebook を加工して作成した。ダッシュボード向けの記述を、スライド向けに読み替えている。各ファイルの「(p.40)」はガイドブックのページ番号。
