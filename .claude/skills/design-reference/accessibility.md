# アクセシビリティ

誰でも同じ情報を得られるようにするための方針。図表を作るときと、仕上げの確認のときに読む。

## 1. 色とコントラスト（p.38, 47）

- グラフの色の面は背景に対して 3:1 以上、文字は 4.5:1 以上（詳しくは `colors.md`）。
- 色だけで情報を区別しない。印の形、線の種類、塗りの模様、ラベルの直接表示を併用する。

## 2. 見られない人のための代わりの手段（p.56）

| ガイドブックの方針 | このハーネスでの扱い |
|---|---|
| 代替テキストを付ける：グラフに代替テキストを付け、スクリーンリーダーで情報を得られるようにする | 図表の SVG や画像に、何を示しているかと主な数値を短く書いた代替テキストを付ける |
| データテーブルを公開する：データを Excel・CSV や HTML の表で公開し、形式や構造も示す | グラフの元データを、HTML の表として同じファイル内に持たせる（表示しないか、付録のスライドにする）。方法は構築時に決める（推測） |
| 要約したテキストを用意する：主要な指標や傾向を文章と数値で要約し、PDF や HTML で公開する | 各スライドの要点を発表者ノートやタイトルに文章で書く。スライド全体の要約は、必要なときに作る（推測） |

- ガイドブックは、行政などが一般に公開するダッシュボードを想定している（p.56）。スライドでは、公開の範囲に合わせて上の2つ目・3つ目を選ぶ。
