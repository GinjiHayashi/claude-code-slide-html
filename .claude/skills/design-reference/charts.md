# グラフ：選び方と描き方

図表を作るときに読む。色の値は見本の `palette.md`、色の使い方は `colors.md`。

## 1. 指標・表・グラフ

| 形 | 何か | 使う場面 |
|---|---|---|
| 指標 | 判断や行動を左右する情報を端的に表す1つの値 | 結論の数字、全体の合計、達成率（大きな数字の箱） |
| 表 | 値を行と列に並べて整理する | 多くの項目を一覧し、正確な値を読ませたいとき |
| グラフ | 値を位置や長さなどの形に対応させた図 | 差・傾向・構成比を直感的に見せたいとき |

## 2. グラフの選び方

| 伝えたいこと | 選ぶグラフ | 値の表し方 |
|---|---|---|
| 時間の変化と傾向 | 折れ線グラフ | 位置 |
| 分類ごとの数量の比較 | 棒グラフ | 長さ |
| 数量と構成比の時間の変化 | 積み上げ面グラフ（構成比だけなら 100% 積み上げ面グラフ） | 位置、面積 |
| 構成比（全体の総量がはっきりしているとき） | 円グラフ・ドーナツグラフ | 角度、面積 |
| 量と推移を同時に（例：件数と割合） | 複合グラフ（量は棒、推移は折れ線） | 長さ＋位置 |

迷ったときの判断：

- 横軸が時間でなければ、折れ線ではなく棒グラフにする。
- 時刻ごとの数量の比較なら、折れ線か面グラフにする。
- 構成比が要らなければ、面グラフではなく折れ線グラフにする。系列が多い、または時間の変化を見せないなら棒グラフにする。
- 円グラフは、全体の総量が明らかで構成比をコンパクトに伝えたいときだけ。多くの場合は棒グラフの方が正確に伝わる。総量が時間とともに変わるなら面グラフにする。

## 3. グラフごとの描き方

**折れ線グラフ**

- 縦軸は数量、横軸は時間。
- データ点に丸や四角などの印を置き、補間した部分と区別できるようにする。
- 系列が複数あるときは系列名を書き、できる限り線の近くに置く（離れた凡例にしない）。
- 使い方の例：2つの系列の比較、参照値（帯で示す）との比較、目標値（点線）との比較。

**棒グラフ**

- 一方の軸に数量、もう一方に分類。棒と棒の間には隙間を空ける。
- 系列が複数なら、並べる（集合棒グラフ）か、積み上げて構成比を示す（積み上げ棒グラフ）。
- 原点は0にする。

**面グラフ**

- 折れ線に塗りを加えたもの。主に複数の系列を積み上げて使う。
- 系列名は、それぞれの面の右端の近くに置く。

**円グラフ・ドーナツグラフ**

- 各分類に、分類名と数値（割合または数量）をできる限り併記する。
- ドーナツグラフは、中央に全体の総量を書ける。
- 12時の位置から時計回りに、大きい順に並べる（ガイドブックの図からの読み取り。推測）。

## 4. どのグラフにも共通すること

- 色数は1〜5色程度に絞る。注目させたい系列だけ色を付け、他はグレーにする。
- タイトルには、内容とデータの種類（月次推移、累計など）を書く。
- 凡例はグラフの隣に、グラフと同じ順で置く。
- 目盛線・枠線は最小限。3D や影は使わない。
- 棒グラフの原点は0。軸の範囲を恣意的に決めない。
- 色だけで系列を区別しない。印の形、線の種類、塗りの模様も変える。
- 更新日・出典・いつ時点の値かを、スライドの下などに書く。
