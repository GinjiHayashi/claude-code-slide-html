# 仕上げのチェックリスト

最終確認（`make-slides` の工程5）で、人間が `deck.html` の見た目を確かめるときに使う確認表。「構成」の節は、構成を見せるとき（`slide-outline` の手順 8）にも使う。AI はこの表でスライドをレビューしない（CLAUDE.md の原則6）。ガイドブックのチェックリストを、スライド向けに読み替えた。

- 「機械」：ビルドの検査（`html-build`）が確かめ、`build-log.md` に結果が出る項目。
- 「部品」：部品の作りで守られる項目（検査はしない）。自由図（`canvas`）と独自の表現（`html:`）は、人が見る。
- 「機械（未実装）」：スクリプトで確かめられるが、まだ検査に入っていない項目。今は人が見る。
- 「人」：人間が見て判断する項目。

## 構成

構成のフレームワーク（`slide-outline/structure-framework.md` 6章）のうち、人が見る項目。機械の項目は、構成のときの検査（`check-brief.mjs`・`check-knowledge.mjs`・`check-outline.mjs`）がエラーか注意で知らせる。

| 項目 | 確認 |
|---|---|
| 持ち帰りの1文を30〜45秒で口で説明できるか（エレベーターテスト） | 人 |
| 前提知識の割合の見積もりが、聞き手に合っているか | 人（5割未満は機械が注意） |
| スライドの並びが知識マップの層の順に従っているか。違うところに理由があるか | 人（`check-knowledge.mjs` の候補と並べる） |
| 前方参照がないか（あとで説明する概念を先に使っていないか） | 機械（`new`・`uses`。知識マップがあるとき） |
| 予告（目次、冒頭の答え）で出した言葉を、根拠に使っていないか | 人 |
| 冒頭の2〜3枚で、状況・問題・問い・答えの予告（SCQA）を示しているか | 人 |
| 各スライドが前のスライドの問いに答え、次の問いを生んでいるか | 人（`question` の書き漏れは機械。`story.mjs` の一覧で見る） |
| タイトルだけを順に読んで、話が通るか | 人（`story.mjs`） |
| 最後に、冒頭の問いにはっきり答えているか | 人 |
| タイトルが1文の主張か。1枚に1つの主張か | 人 |
| 各タイトルに「だから何？」（持ち帰りの1文への寄与）を答えられるか。答えられないスライドは削る候補 | 人 |
| 新しく出す抽象の概念に、具体（類推・図・例）と技術的な定義があるか | 機械（`adept`） |
| 類推に、成り立たなくなる点を添えているか | 人 |

## 聞き手の体験

| 項目 | 確認 |
|---|---|
| 聞き手が判断や行動に必要な情報を出しているか | 人 |
| 全体像をつかむための基準になる数字（全体の合計、結論の数字）を最初に出しているか | 人 |
| 本当に必要な情報だけに絞れているか。ほとんど使わない情報が載っていないか | 人 |
| 1枚を読み解くのに、口頭の補足が要りすぎないか | 人 |
| 複数の人のフィードバックを得て直したか | 人 |

## 指標・表・グラフ

| 項目 | 確認 |
|---|---|
| 聞き手が見たい数字に最初に目が向くか | 人 |
| グラフや表の並び順に意味があるか（大小順、時系列順） | 人 |
| 凡例がグラフの隣にあり、グラフと同じ順か | 人 |
| 他のデータとの比較や時間の変化で、違いにすぐ気づけるか | 人 |
| グラフの色数が1〜5色程度か | 機械（未実装） |
| 目盛線や枠線が最小限か | 人 |
| 3D、影などの装飾を使っていないか | 部品（`theme.css` に影や立体の値がない） |
| タイトルや系列名が、誰が見てもわかり、誤解がないか | 人 |
| 棒グラフの原点が0か | 部品（`bar`・`hbar`・`stacked-bar` は原点が0） |
| データの更新日（いつ時点の値か）を書いているか | 機械（未実装） |

## データ

| 項目 | 確認 |
|---|---|
| 目的に合ったデータだけを選んでいるか | 人 |
| 聞き手が見たい細かさまで分けて示しているか | 人 |
| 数字だけで判断しにくいときに、比較できる数字（目標値、前年比など）を載せているか | 人 |
| データの定義（何を対象に、何を数えたか）と出典を書いているか | 機械（未実装。出典の有無） |

## アクセシビリティ

| 項目 | 確認 |
|---|---|
| 色だけでグラフの情報を区別していないか | 人 |
| グラフの色が背景に対して 3:1 以上、文字が 4.5:1 以上か | 部品（色は `theme.css` のトークンだけ。3:1 に届かない色の棒には数値を書く） |
| グラフに代替テキストを付けているか | 部品（SVG のグラフに `aria-label`。HTML の棒グラフは数値を字で書く） |

## 表示

| 項目 | 確認 |
|---|---|
| 発表する環境（プロジェクター、PDF、印刷）で問題なく表示されるか | 人 |
| ファイルが重すぎないか（開くのに時間がかからないか） | 機械（`build-log.md` に大きさが出る。重すぎるかの判定はない） |
