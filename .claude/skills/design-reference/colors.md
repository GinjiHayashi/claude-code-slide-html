# 色：役割と使い方

色を決めるとき、図表に色を付けるときに読む。具体的な色の値は、見本の `palette.md` にある。

## 1. 色は役割で決める

色は1つずつ選ばず、役割ごとに決めた色を使う。見本の `palette.md` は、次の役割それぞれに値を持つ。

| 役割 | 中身 |
|---|---|
| 文字 | 本文、補足（ラベル）、リンク、濃い背景の上の文字 |
| 背景 | 標準の背景、強調の背景、パネル（カード）の背景 |
| グラフ：主 | 主役の系列に使う色の濃淡（1つの色相の段階） |
| グラフ：副 | 主と区別したい系列に使う、別の色相 |
| グラフ：中立 | 比較対象・その他の系列に使うグレーの段階 |
| 意味のある色 | 増加（Positive）と減少（Negative）、成功（Success）とエラー（Error） |

- 1つの色相の濃淡を基本にし、副の色や意味のある色は必要な場面だけに使う。
- 「増加＝青、減少＝赤」のように意味を決めた色は、他の用途に使わない。
- 見本を差し替えるときは、同じ役割の値を用意する（同じ役割の構成のまま、色相だけを変えられる）。

## 2. 色数

- 1枚のグラフに使う色は1〜5色程度にする。
- 注目させたい系列だけに色を付け、他はグレーにする。

## 3. コントラスト

| 対象 | 背景に対するコントラスト比 |
|---|---|
| グラフの色の面（棒、面、線） | 3:1 以上 |
| 文字（グラフの中の数値を含む） | 4.5:1 以上 |

- グラフの色が 3:1 に届かないときは、その面のすぐ近くに数値を書く。数値の色は 4.5:1 以上にする。
- 見本の `palette.md` に、各段階が白背景で 3:1、4.5:1 を満たすかを書く。
- 「マウスを乗せたら数値を出す」方法は、印刷や PDF では使えないため、このハーネスでは使わない（このハーネスの判断）。

## 4. 色覚の多様性

- 色だけで区別しない。印の形、線の種類（実線・点線）、塗りの模様、ラベルの直接表示を併用する。
- 白黒で印刷しても伝わるかを確かめる。
- 見分けにくい組み合わせ（赤と緑など）を避け、色覚シミュレーションで確認する。
