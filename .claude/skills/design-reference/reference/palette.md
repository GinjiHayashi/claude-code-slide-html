# カラーパレット（見本：デジタル庁 ダッシュボードガイドブック）

`colors.md` の役割に、この見本の値を当てはめたもの。`theme.css` のトークンはここから作る。

- 値はガイドブック p.35（7系統の段階）と p.36（役割ごとの構成、Blue の場合）に書かれた16進数を写した。
- 「白との比」は、白背景（#FFFFFF）とのコントラスト比を WCAG 2.x の式で計算した値（このハーネスで計算。ガイドブックには数値はなく、p.35 に 3:1・4.5:1 の目安の位置だけがある）。
- 元は Power BI 用のテンプレートの配色。デジタル庁デザインシステムのカラーパレットを踏襲している（p.35）。

## 3. スライドで実測した色との対応

`slide-style.md` の5は、ガイドブック自身のスライドの画像から取った色。パレットの値とは一致しないものがある。

| 実測（slide-style.md） | 近いパレットの値 | メモ |
|---|---|---|
| プライマリー `#0031D8` | Blue 900 `#0017C1` | 画像の圧縮や色の変換でずれた可能性がある（推測） |
| 塗りの強調 `#264AF4` | Blue 600 `#3460FB` | 同上（推測） |
| 本文 `#1A1A1C` | SolidGray 900 `#1A1A1A` | スライドの本文は純粋な黒ではない |
| 補足の文字 `#626264` | Label `#626264` | 一致 |
| パネルの背景 `#F8F8FB` | Standard `#F8F8FB` | 一致 |
| 良い例 `#259D63` | Green 600 `#259D63` | 一致 |
| 悪い例 `#CE0000` | Red 900 `#CE0000`（Error） | 一致 |

- `theme.css` では、パレットの値（左ではなく中央の列）を使うことを提案する。理由：出典に書かれた値で、実測の誤差を含まないため。
