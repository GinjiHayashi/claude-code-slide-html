# 見本（参考スライド）の置き場所

デザインの手本にする資料を、1つにつき1フォルダで置く。いま使う見本は、1つ上の `active.yaml` で選ぶ。

```
references/
└── <id>/                 # 英小文字とハイフン（例：digital-agency-dashboard）
    ├── README.md         # 出典、取得手順、版、利用条件、出典の書き方
    ├── slide-style.md    # スライドとしての作り：スライドの種類、余白、文字の大きさ、色の使い方（実測）
    ├── palette.md        # colors.md の役割ごとの色の値と、白とのコントラスト比
    └── source.<拡張子>   # 元資料（PDF など）。git 管理外
```

## 新しい見本を追加する

1. フォルダを作り、元資料を `source.<拡張子>` で置く。公開リポジトリに入れないため、`.gitignore` で除外されている。
2. `README.md` に、出典の URL、取得手順、版（日付・ページ数・ファイルサイズ）、利用条件を書く。利用条件は `license-notice/policy.md` の区分で確かめる。
3. `slide-style.md` と `palette.md` を、`digital-agency-dashboard/` と同じ見出しで書く。値が見本にない項目は「なし」と書き、空欄にしない。
4. 人間が内容を確認してから、`active.yaml` を書き換える。

## 守ること

- 元資料の図・文章・ロゴ・組織名の表記は、スライドに転載しない。参考にするのは考え方と作り。
- 元資料を加工して作ったファイルには、出典と「加工して作成」の旨を書く。
