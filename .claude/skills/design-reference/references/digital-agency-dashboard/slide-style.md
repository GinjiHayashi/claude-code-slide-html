# スライドの作り（ガイドブック自身のスライドから抽出）

デジタル庁「ダッシュボードデザインの実践ガイドブック」（2026年3月31日更新、59ページ、16:9）の**スライドとしての作り**をまとめたもの。`layout-catalog.md` と `theme.css` を作るときの手本にする。

- 寸法は、ガイドブックの1ページ（1920×1080）を基準にした実測値。右の列は、このハーネスのスライド（1280×720）に換算した値（×2/3）。
- 色は、ページの画像から取った実測値。
- 「(p.5)」はガイドブックのページ番号。元の PDF はこのフォルダの `source.pdf`（git 管理外。取得手順は `README.md`）。

## 1. 守ること（写さないもの）

- 左上の「デジタル庁」の表記、右下の「©2026 Digital Agency」は写さない。自分たちのスライドが政府の資料に見えるのを避けるため。公共データ利用規約（PDL1.0）でも、ロゴ等は対象外。
- 参考にするのは、構成・余白・文字の大きさ・色の使い方の**考え方**。ガイドブックの図やイラストをそのまま転載しない。

## 3. 余白と配置

| 項目 | 実測（1920×1080） | 換算（1280×720） |
|---|---|---|
| 左右の余白 | 約 80px | 約 54px |
| タイトルの上端 | 約 95px | 約 63px |
| タイトルから本文までの間隔 | 約 75px | 約 50px |
| 本文の列幅（左文・右図のとき） | 約 840px（全体の約 44%） | 約 560px |
| フッター（ページ番号など）の位置 | 下端から約 40px、右寄せ | 下端から約 27px |

- フッターは右下に「著作権表記」と「ページ番号」を並べる（p.5 など）。このハーネスでは、著作権表記の代わりに出典やスライドの名前を置く（推測。構築順序4で決める）。
- 章の扉は、タイトル・横線・節の一覧が縦の中央にそろう（p.8）。

## 4. 文字

| 用途 | 実測の文字の高さ（1920×1080） | 推定の文字サイズ（1920×1080 → 1280×720） | 太さ・色 |
|---|---|---|---|
| 扉の章タイトル | 約 120px | 約 96px → 64px | 標準・白 |
| ページのタイトル | 約 50px | 約 56px → 37px | 太字・プライマリーの青 |
| 小見出し | 約 24px | 約 28px → 19px | 太字・本文色 |
| 本文 | 約 21px、行の間隔は約 41px | 約 24px → 16px、行の高さは約 1.7 | 標準・本文色 |
| パンくず（所属する節名） | — | タイトルの約半分 | 太字・プライマリーの青 |
| フッター | 約 15px | 約 16px → 11px | 標準・本文色 |

- 文字サイズは、文字の高さの実測から逆算した推測値。
- 書体は Noto Sans JP（Source Han Sans）系の見た目。PDF にフォント名が残っていないため、見た目からの推測。このハーネスで使う Noto Sans JP と同じ系統。

## 5. 色の使い方（実測）

| 役割 | 色 | 使われている場所 |
|---|---|---|
| プライマリー | `#0031D8` | 表紙・扉の背景、ページのタイトル、強調の文字 |
| 塗りの強調 | `#264AF4` | 表の見出し行、強調する箱（p.10 の「Why」）、グラフ |
| 本文 | `#1A1A1C` | 本文、小見出し |
| 補足の文字 | `#626264` | カードや表の中の説明 |
| 淡い青の面 | `#E8F1FE` | 強調したいカードの背景（p.5「本書の対象範囲」） |
| 淡い青の背景 | `#D9E6FF` | 淡色の扉（p.27） |
| パネルの背景 | `#F8F8FB` | 表の本文の行、良い例・悪い例のパネル |
| 薄いグレーの面 | `#F2F2F2` | 対象外のものを示すカード（p.5「探索型」） |
| 良い例 | `#259D63` | 「Do」の帯とアイコン |
| 悪い例 | `#CE0000` | 「Don't」の帯、注記の枠 |

- 色は1枚の中で「青の濃淡＋グレー」に絞り、緑と赤は良い例・悪い例のような意味のある場面だけに使っている。
- カラーパレットの正式な値（Blue 900 など）と、上の実測値との対応は `palette.md` にある。

## 6. このハーネスに取り入れること（提案）

| 取り入れること | 反映先 |
|---|---|
| 表紙・目次・章の扉・本文（左文・右図）・表・良い例と悪い例・流れ・原則の一覧を、スライドの型にする | `layout-catalog.md` |
| 余白・文字サイズ・色の値を、トークンにする | `theme.css` |
| タイトルは左上・青・太字、本文は黒、強調は青の濃淡、緑と赤は意味のある場面だけ、という使い分け | `theme.css`、機械的なチェック |
| 章の導入スライドの「ゴール」「使うもの」や、工程の帯は、長いスライドで今どこにいるかを示すのに使える（推測） | `layout-catalog.md`（候補） |
