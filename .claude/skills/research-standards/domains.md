# 情報源のドメインの一覧

調査とファクトチェックで、どのサイトを優先し、どのサイトを使わないかの一覧（要求文書 7.4「ドメインの許可・除外リスト」「情報源に優先順位を付ける」）。

- **人間が管理する固定ファイル。** AI は変えない。足したいドメインがあれば、理由を添えて人間に提案する。
- 表の「ドメイン」は、そのドメインと、その下のサブドメインすべてに当てはまる（例：`go.jp` は `www.e-stat.go.jp` も含む）。
- WebSearch の `allowed_domains` に「優先」を、`blocked_domains` に「除外」を渡す。`check-research.mjs` は「引用しない」と「除外」の URL を出典にするとエラーにする。

## 優先（一次情報）

最初の検索は、このドメインに絞って行う（`allowed_domains`）。見つからないときに絞り込みを外す。

| ドメイン | 中身 |
|---|---|
| go.jp | 国の行政機関（省庁、デジタル庁、e-Stat、e-Gov 法令検索など） |
| lg.jp | 地方公共団体 |
| ac.jp | 大学・研究機関 |

- 上の表のほか、調べる対象そのものの公式サイト（製品の公式ドキュメント、企業の公式発表、団体の公式サイト）も一次情報として扱う。対象ごとに変わるので、表には載せない。

## 引用しない（手がかりにだけ使う）

検索結果に出てきてよいが、出典には書かない。中に書かれた原典をたどり、原典を出典にする。

| ドメイン | 理由 |
|---|---|
| wikipedia.org | 誰でも編集でき、内容が変わる |
| weblio.jp | 辞書・用語集の転載が多い |

## 除外

検索に使わない（`blocked_domains`）。出典にするとチェックでエラーになる。

| ドメイン | 理由 |
|---|---|
| chiebukuro.yahoo.co.jp | Q&A サイト。回答者の確かさがわからない |
| oshiete.goo.ne.jp | Q&A サイト |
| matome.naver.jp | まとめサイト（終了済み。古い転載が残る） |
| togetter.com | SNS の投稿のまとめ |

## 情報源の段階（tier）

`research.md` の `tier` は次の4つ。ドメインだけでは決まらないので、ページの中身で判断する。

| tier | 例 |
|---|---|
| 一次 | 公式ドキュメント、公的機関の資料・統計、論文、企業・団体の公式発表 |
| 準公式 | 公式ブログ、カンファレンスの発表資料、公式の担当者による記事 |
| 二次 | ニュース、技術記事、業界誌 |
| 個人 | 個人ブログ、SNS、掲示板 |
