# 図の型の一覧（diagram-catalog）

`outline.md` の `diagram:` には、この一覧の型の名前（`kind:`）と、その型が求める項目だけを書く。運用時は固定で、スライドごとに型を足したり変えたりしない。

**書ける項目**は、この一覧には書き写さない。`node .claude/skills/html-build/scripts/schema.mjs <kind>` で出す（`?` の付いた項目は任意。正は各部品の `schema`）。値の意味と既定は、部品（`html-build/components/<kind>.mjs`）の冒頭のコメントにある。知らない項目を書くと、ビルドがエラーで止まる。並びの**数の決まり**（`items` は2〜6、表の行は8まで など）も同じ出力の「数：」に出る（正は各部品の `limits`）。下の表の数は目安の写しで、食い違ったら `schema.mjs` に従う。

**部品の使い方**：型（部品）は道具であり、どのスライドも必ずどれかの型で描かなければならないわけではない。
- 先に `outline.md` の `idea` で見せたい絵を決め、それを部品で描けるかを `match` に書く（`outline-template.md` 4章）。
- `match` が「そのまま」なら、**必ずその型を使う**。たとえば一列の流れを示すのに `flowchart` で描けるのに、似たものを独自に作らない。
- 「意味が欠ける」（描けるが `idea` の大事な点が消える）「描けない」なら、無理に当てはめない。まず自由図 `canvas`（6章）で描く。`canvas` でも描けないときだけ、独自の表現として書き（`html-build/components.md` 4.1：トークンだけを使う、枠に収める）。ビルドが `build-log.md` の注意に自動で載せるので、人間に報告する。

- 図はすべてビルド時に描き、HTML に埋め込む。表示するときに何も読み込まない。
- グラフの選び方と描き方の考え方は `design-reference/charts.md`。この一覧は、それを型に落としたもの。
- 図を置ける大きさは、スライドの型で決まる（`layout-catalog.md`）。`title-diagram` は幅 1172、`text-diagram` の右側は幅 572。高さは、タイトルと説明文の下の残り（説明文の行数で変わり、最大 496）をビルドが測って渡す（`html-build/layouts.mjs`）。

## 1. すべての型に共通すること

| 項目 | 決まり |
|---|---|
| 色 | `theme.css` のトークンだけを使う。注目させたいもの（`highlight: true`）だけ `primary` の青、ほかは `gray-400` など灰色 |
| 色数 | 1つの図で5色まで。緑と赤は、良し悪しの意味があるときだけ |
| 強調表示 | 大きな数字で示す値（「1/7」「+12%」など）は `callout: {value, label}` に書く。部品は計算しない（承認とファクトチェックの対象にするため） |
| 単位 | 数量を扱う型では `unit:` を必須にする |
| 出典・時点 | 図の中には書かず、スライドの `source:` に書く |
| 文字 | 図の中の文字は `text-caption`（12px）以上（地図 `map` のタイルの、3文字の都道府県名だけ `text-footer`（11px））。検査は 11px 未満を不合格にする（12px との間は人が見る）。ラベルは全角12字までを目安にし、超えるならデータの名前を短くする |
| 区別 | 色だけで区別しない。線の種類、印の形、ラベルの直接表示も使う |

## 2. 型の一覧

描き方の欄：**CSS** は HTML/CSS（Tailwind）の部品、**SVG** は HTML/SVG の部品（座標はビルド時に d3-scale・d3-shape で計算）、**SVG/CSS** は箱を HTML、矢印を SVG で描く部品。外部の作図ツール（Mermaid など）は使わない（配置を指定できず、レイアウトが崩れる元になるため）。

### 2.1 データ

| 型（kind） | 用途 | 制約 | 描き方 |
|---|---|---|---|
| `kpi` | 結論の数字を大きく見せる | 1〜4個を横に並べる。ラベル・数字・比較の行の高さはカードどうしでそろう。枠が狭く1枚の幅が160px未満になるときは、1枚を1行にして縦に積む | CSS（trend は SVG） |
| `bar` | 分類ごとの量を比べる（縦棒） | 2〜12本。原点は0 | CSS |
| `hbar` | 項目名が長い比較、順位（横棒） | 2〜10本。大きい順に並べる | CSS |
| `stacked-bar` | 量と内訳を同時に見せる | 系列は5まで、分類は8まで | CSS |
| `line` | 時間の変化と傾向 | 系列は4まで、時点は24まで。系列名は線の右端に直接書く | SVG |
| `area` | 量と構成比の時間の変化 | 系列は5まで。系列名は面の右端に書く | SVG |
| `combo` | 量（棒）と推移（線）を同時に | 棒と線を1系列ずつ。軸は左右に分ける | SVG |
| `donut` | 全体が明らかなときの構成比 | 5項目まで（超える分は、自分で「その他」の項目にまとめる）。12時から時計回りに大きい順。多くの場合は `hbar` の方が正確に伝わる | SVG |
| `scatter` | 2つの量の関係 | 点は50まで。ラベルは注目する点だけ | SVG |
| `table` | 正確な値を一覧で読ませる | 8行×6列まで。数値は右寄せし、小数の桁を列で揃える。見出し行は `primary` の塗りに白文字。セルの `` `…` `` は文中のコード（Roboto Mono）で出る。既定の見た目は `grid`（外枠と行の区切りの線）。ほかの見た目（`style`）は `table.mjs` の冒頭 | CSS |

### 2.2 構造・時間

| 型（kind） | 用途 | 制約 | 描き方 |
|---|---|---|---|
| `flowchart` | 流れ図。一列の流れから、枝分かれ・合流・戻りまで | 箱は12まで。一列なら nodes を並べるだけで順につなぐ。`col`・`row` は 0 から数える（1 から書いても、図は枠の中央に置かれる）。矢印は縦横の線を角の丸い（半径 8）折れ線でつなぐ | SVG/CSS |
| `steps` | 順番に行う手順 | 横は3〜5段、縦は3〜6段。番号を付けて線でつなぐ | CSS |
| `timeline` | 出来事を時間順に | 3〜6個 | CSS |
| `roadmap` | 期間のある計画 | 期間は8列まで、レーンは4まで | CSS |
| `dirtree` | フォルダとファイルの階層（ディレクトリツリー） | 16行まで（多いときは `...` で省く）。字下げで階層、名前の最後の `/` でフォルダ、`# 説明` で右の列の説明、行の頭の `* ` で強調。フォルダはアイコンと名前を紺、ファイルは灰色のアイコンと黒の名前、強調は太字の青。字は Roboto Mono | SVG/CSS |

### 2.3 概念

| 型（kind） | 用途 | 制約 | 描き方 |
|---|---|---|---|
| `matrix` | 2つの軸で4つに分ける | 各マスは短い文（text）と箇条書き（items、3つまで）のどちらか、または両方。軸は両矢印。軸の名前は矢印に重ねず、横軸は下・縦軸は左の中央に置く | CSS |
| `pyramid` | 土台から上へ積み上がる関係 | 3〜5段。上が頂点 | CSS |
| `tree` | 階層（組織、分類） | 3階層まで。1つの親の子は5まで。down は孫を子の下に縦に積む。線は矢印にせず、直角に折れる線（tree だけの例外） | SVG/CSS |
| `cards` | 同じ重さの項目をカードにして並べる | 2〜6枚を2〜3列。見出しの帯と説明を1枚の実線の枠に入れ、帯と説明の高さを同じ段のカードどうしでそろえる。`tone`（plain・primary・soft・muted）で見出しの帯を塗り分ける。`summary` で下にまとめの帯（見出しの帯と同じ高さ）。`icon` か `numbered` で見出しの左に印 | CSS |
| `cycle` | 一周して戻る循環 | 3〜6個。`ring`（輪。4つなら四角の角）か `row`（横に並べ、下を通って戻る）。箱の文字の頭に番号の小さい丸（24px。`numbered: false` で消す）。`exit` で輪の右に抜け出す先を1つ（輪の箱と横に等間隔）。`tone`（ink・primary・muted）で輪の色、`title` で見出し、`frame` で輪を囲み（primary は淡い青の面、ほかは灰色の点線）に入れる | SVG/CSS |
| `layers` | 帯を重ねた層 | 3〜6層を上から下へ。帯の文は「名前：説明」。`tone`（plain・primary・soft・muted）で帯を塗り分ける。`top`・`bottom` で左に上下両向きの矢印と両端のラベル。層の並びが資料にない整理なら `note` で図の下に注記（例：層の並びは AI が整理したもの） | CSS |
| `hub` | 1つの共通の口に、複数のものがつながる | 上に1つの箱（青地）、真ん中に横長の帯（`hub`。淡い青、`text` で（…）の説明）、下に2〜6個の箱と短い説明（2行まで）。上と帯は両向きの矢印、帯と下の箱は線 | SVG/CSS |
| `nested` | 入れ子の包含関係 | 3〜6段を外から順に。各段の囲みの左上に「名前：一言の説明」。いちばん内側は青地の箱で目立たせる。ほかの段は `tone`（plain・soft・muted） | CSS |
| `flow-notes` | 流れの各段と、それぞれへの説明 | 2〜5個。上に流れの箱（右向きの矢印でつなぐ）、その下に説明の箱（淡い青。高さをそろえる。説明から箱へ上向きの矢印）、`base` でいちばん下に横長の帯（青地。帯から説明へ上向きの矢印） | CSS |
| `compare` | 選択肢を観点ごとに比べる | 観点は6まで。推奨の列を淡い青で塗り、見出しの上に「推奨」と書く。記号は小見出しの大きさ、文を添えるときは記号の下に書く | CSS |

## 3. 図の中で使える補助

| 補助 | 使い方 | 描き方 |
|---|---|---|
| 数式 | `math: 式`（TeX の記法）。必要な場合だけ | KaTeX でビルド時に変換 |

d3・KaTeX は、license-notice の許可済み一覧に載っているものだけを使う。

## 4. 型を選ぶ目安

- 数字1つで結論が言える → `kpi`
- 分類で比べる → `bar`。項目名が長い・順位 → `hbar`。内訳も見せる → `stacked-bar`
- 時間で変化する → `line`。構成比の変化も見せる → `area`。件数と率のように単位が違う2つ → `combo`
- 正確な値や設定値を一覧で読ませる → `table`。説明の並び（「やりたいこと → 使う機能」など）は表にせず、カードや関係図にする
- 選択肢の比較 → `compare`。2つの軸で整理 → `matrix`
- 流れ → `flowchart`（一列でも、枝分かれ・合流・戻りがあっても）。手順 → `steps`（時間や手順の**順序があるときだけ**。同じ重さの項目を並べるだけなら、番号を付けずにカード〔`cards`〕にする）。日付がある → `timeline`、期間がある → `roadmap`
- 人やシステムのやりとりの順番 → `sequence`。データの項目と関係 → `er`。組織や分類の階層 → `tree`。フォルダとファイルの階層 → `dirtree`。段階 → `pyramid`。集合の重なり → `venn`
- 2つの分類の組み合わせごとの値 → `heatmap`。都道府県ごとの値 → `map`。式や定義 → `math`。写真や画面 → `image`。プログラムのコード → `code`（文中の短いコードは `` `…` ``。`html-build/components.md` 4.3）
- 同じ重さの項目を2〜6つ並べる → `cards`（重さの違いは `tone`、まとめは `summary` の帯）
- 循環（一周して戻る）→ `cycle`（抜け出す先は `exit`。2つの循環を比べるときは `diagrams` に `cycle` を2つ）
- 層（帯を重ねる）→ `layers`。1対多の接続（共通の口に複数がつながる）→ `hub`。包含（入れ子）→ `nested`
- 流れの各段に、それぞれの説明や守ることを添える → `flow-notes`（枝分かれや戻りがある流れは `flowchart`）
- どの型でも `idea` の絵が描けない、いくつかの型を組み合わせたい → `canvas`（6章）
- 2つの図を左右に並べる（`diagrams`）ときは、上端がそろう。ずれたら `npm run shots` で撮って確かめる（`html-build` の「画像で確かめる」）

## 5. そのほかの型

| 型（kind） | 用途 | 制約 | 描き方 |
|---|---|---|---|
| `map` | 都道府県ごとの値を色の濃さで示す（コロプレス） | 色は青の濃淡5段階まで | SVG |
| `heatmap` | 2つの分類の組み合わせごとの値を色の濃さで示す | 12行×12列まで。値も数字で併記する | CSS |
| `sequence` | やりとりの順番（シーケンス図） | 登場する人やシステムは5まで、やりとりは10まで | SVG/CSS |
| `er` | データの項目と関係（ER 図） | 表は6まで | SVG/CSS |
| `venn` | 2〜3つの集合の重なり | 集合は3つまで | SVG |
| `image` | 写真・画面の写し・1色のアイコンを1つ置く | アイコンは `src: phosphor:<名前>`（`html-build/scripts/icons.mjs` で探す）。写真などは `outline.md` の先頭の `assets` にあるものだけ（`license-notice/policy.md` 5章）。角は半径 8 で切り抜き、薄い枠を付ける。`alt` は必須 | CSS |
| `code` | プログラムのコードを見せる（コードブロック） | 枠に収まる行数と長さまで（長い行は折り返さない）。言語は部品の `LANGS` から選ぶ。色は GitHub Light Default、字は Roboto Mono | CSS |
| `canvas` | 自由図。形を格子の上に並べて描く（6章） | 形は40まで。すべて格子の中に収める | SVG/CSS |

部品は `html-build/components/` の同名のファイル。`venn` は highlight で全部が重なる部分だけを塗り、`sequence` は応答（reply）を点線、`er` は表の見出しを塗って両端に多重度（1・N）を書く。`map` は style: shape（既定。境界は Natural Earth）と tile（タイルグリッド地図）の2通り。`math` は KaTeX の HTML 出力だけを使う（MathML 出力は環境によって組版が崩れるため）。`code` はビルド時に shiki で色を付ける。KaTeX・Natural Earth・d3-geo・shiki・Roboto Mono は registry.yaml に登録済み。

## 6. 自由図（canvas）

一覧の型で `idea` の絵が描けないとき（`match` が「意味が欠ける」「描けない」）に使う。座標は px ではなく格子のマス目（既定 12列×6行）で、色は役割（`tone`）で書く。部品が `theme.css` のトークンに直し、線の端・矢印の向き・文字の位置・目盛りなどの計算は部品が行う。形の一覧と値の意味は `html-build/components/canvas.mjs` の冒頭のコメント、形ごとに書ける項目は `node .claude/skills/html-build/scripts/schema.mjs canvas`。

| 形のなかま | 形（type） |
|---|---|
| 囲む・置く | `area`（囲み。カードとして使うときは `tone: card` の実線の枠）、`frame`（画面の枠：browser・phone）、`box`（箱：rect・pill・cylinder・document・stack）、`chevron`（工程）、`text`、`icon` |
| つなぐ・示す | `line`（細い線と矢印）、`arrow`（近くの形の間に置く太い矢印。44px の正方形）、`brace`（中括弧）、`note`（吹き出し）、`badge`（番号の丸。`size: small` で小さい丸）、`dot`、`ring`（注目の丸） |
| 数や並びを見せる | `cubes`（立方体のリスト・行列。色を付けて区別）、`plot`（小さな折れ線）、`people`（人の数）、`chart`（一覧の型の部品をそのまま中に置く） |

組み合わせて1つの図にする手順：

1. `idea` の絵を、部分（例：グラフ・注目する点・説明の箱・まとまり）に分ける。
2. 部分ごとに形を選ぶ。一覧の型で描ける部分（棒グラフ・円グラフ・表など）は `chart` で中に置き、それ以外は上の形で描く。
3. 格子の上に置く場所を決める。関係する形には `id` を付け、`line`・`note`・`badge` の相手にする（線の端は相手の縁で止まる）。
4. ビルドの検査（はみ出し・格子の外）で直す。

決まり：`box`・`chevron` の字の大きさは、`text_size`（`body`・`heading`）を書かなければ図の中で1つにそろう。箱の高さは、字の大きさに合わせた最小の高さ（`body` 64px・`heading` 72px）まで、格子の1行の中で広がる。`canvas` の中のアイコンは単体（`icon`）が 64px、文字の横（`box`・`area` の `icon`）が 24px の2つだけ。色は黒・紺・灰色・白だけ。`canvas` の中に `canvas` は入れない。`ring` は `plot` の点（`on`・`point`）か、格子の上の位置（`at`）を囲む。`chart` で置いたグラフの点は `on` では指せないので、`at` で位置を合わせる。
