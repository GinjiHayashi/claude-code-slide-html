# スライドの型の一覧（layout-catalog）

`outline.md` の各スライドの `layout:` には、この一覧の型の名前だけを書く（D3）。運用時は固定で、スライドごとに型を足したり変えたりしない。合う型がなければ近い型で代替し、`build-log.md` に記録して人間に報告する（9.1）。

- 寸法の単位は px。スライドは 1280×720。名前の付いた値（`slide-x` など）は `theme.css` のトークン。
- 文字数の上限は、文字の大きさと置ける幅から計算した値に1字の余裕をみたもの。英数字は全角より幅が狭いので、全角として数えれば安全側になる。最後はビルド時の検査で、実際の行数をブラウザで測って判定する。
- 図・表・グラフ・流れの中身は `diagram-catalog.md` の型を使う。この一覧は、スライドの枠（どこに何を置くか）だけを決める。

## 1. すべての型に共通すること

| 要素 | 決まり |
|---|---|
| 余白 | 左右 `slide-x`（54）、タイトルの上端 `slide-top`（63）、下端 `slide-bottom`（27） |
| タイトル | 左上。`text-title`（36px）・太字・`primary`。前に縦長の帯（幅 8px、高さは文字の 1.25 倍、タイトルとの間 24px、帯と文字の中心を揃える）。**1行のみ、全角30字まで** |
| パンくず（任意） | タイトルの上に、所属する章の名前を `text-breadcrumb`（16px）・太字・`primary` で書く |
| 本文の開始位置 | タイトルの下 `title-gap`（50） |
| 出典・図の番号 | 左下に `text-caption`（12px）・`label` の色で書く |
| ページ番号 | 右下に「n / N」。base.html が自動で付ける。表紙（`title`）には付けないが、数えるときは表紙も1枚と数える |
| 発表者ノート | `notes:` に書く。スライドには出ない |

## 2. 型の一覧

| 型の名前 | 用途 | 枠（必須） | 枠（任意） | 制約 |
|---|---|---|---|---|
| `title` | 表紙 | title | subtitle, date, author | 下の 3.1 |
| `toc` | 目次 | items | — | 章の数は8まで |
| `section` | 章の扉 | title | items | 下の 3.2 |
| `title-body` | 文章中心 | title, body | breadcrumb, source | 箇条書きは5項目まで、各項目は2行まで |
| `text-diagram` | 左に文章・右に図 | title, body, diagram | breadcrumb, caption, source | 文章の列は幅 `column`（560）。箇条書きは4項目まで |
| `title-diagram` | 図が中心 | title, diagram | breadcrumb, caption, source | 図は高さ 500 まで（画面の約 70%） |
| `two-column` | 2つを比べる | title, left, right | breadcrumb, source | 左右とも、小見出し1つと箇条書き4項目まで |
| `do-dont` | 良い例と悪い例 | title, do, dont | breadcrumb, body | `do` は上端に `success` の帯、`dont` は上端に `error` の帯。緑と赤はこの型だけで使う |
| `grid-4` | 原則や要点を4つ並べる | title, items（4つ） | breadcrumb | 2×2。各項目は小見出し（全角15字まで）と説明（3行まで）。アイコンは任意 |
| `credits` | ライセンス表記 | — | — | license-notice のスクリプトだけが作る。outline.md には書かない |

## 3. 表紙と章の扉

背景は白、左端に `primary` の帯（幅 `strip`＝20）。全面を濃い青にしない（ユーザーの決定。青の面積が大きいと見づらいため）。

### 3.1 表紙（`title`）

| 枠 | 書き方 | 上限 |
|---|---|---|
| title | `text-cover`（48px）・太字・`primary` | 2行まで、1行あたり全角22字 |
| subtitle | `text-heading`（20px）・`ink` | 1行、全角50字 |
| date | `text-body`（16px）・`label` | 1行。例「2026年10月17日」 |
| author | `text-body`（16px）・`label` | 1行、全角50字。組織名や発表者名 |

- 左端は x=80（帯の右から 60）。
- タイトル・副題・日付・発表者を**ひとまとまりにし、全体を縦の中央に揃える**。どの枠を省いても、残ったまとまりが中央に来る。
- 文字の見た目の中心を合わせるため、まとまり全体を 0.04 文字分だけ上にずらす（Noto Sans JP での実測）。
- 順番は上から title → subtitle → date → author。title と subtitle の間は 16、subtitle と date の間は 32。

### 3.2 章の扉（`section`）

| 枠 | 書き方 | 上限 |
|---|---|---|
| 章番号 | 「CHAPTER 1」の形。`text-heading`（20px）・太字・`blue-600`。**自動で付ける**（outline.md には書かない） | — |
| title | `text-section`（64px）・太字・`primary` | 1行、全角16字 |
| items | その章で話す項目。`text-body`（16px）・`label` | 3〜5項目、各全角30字 |

- 本文のスライドと見分けやすくするため、章番号と大きなタイトルを必ず出す。
- 表紙と同じく、章番号・タイトル・項目をひとまとまりにして縦の中央に揃える。

## 4. 型を選ぶ目安

- 結論や主張を言葉で伝える → `title-body`
- 図・グラフ・表を見せる → 説明が要るなら `text-diagram`、図だけで伝わるなら `title-diagram`
- A と B を比べる → `two-column`。正しい・誤りの対比なら `do-dont`
- 同じ重さの要点が4つ → `grid-4`（3つや5つなら `title-body` の箇条書き）
- 5枚を超えるデッキは `section` で章を区切り、10枚を超えるなら `toc` を入れる（推測。試作のレビューで決める）

## 5. まだ型にしていないもの（候補）

見本にはあるが、今は型にしないもの。必要になったらハーネスの変更として追加する。

| 候補 | 見本での使い方 | 今は入れない理由 |
|---|---|---|
| 章の導入 | 章タイトル・説明・ゴール・工程の帯 | `section` と `two-column` で代わりができる |
| チェックリスト | チェック欄と項目の一覧 | 発表用のスライドでは使う場面が少ない（推測） |
| 締め・裏表紙 | 青の全面、または文字なし | 締めは `section` か `title-body` で足りる |

---

出典：寸法・文字・色の考え方は `design-reference/reference/slide-style.md`（デジタル庁「ダッシュボードデザインの実践ガイドブック」のスライドから抽出）にもとづく。表紙・章の扉の配色（白地＋左端の帯）、タイトルの帯、文字数の上限は、このハーネスの構築時にユーザーが決めた。
