# スライドの型の一覧（layout-catalog）

`outline.md` の各スライドの `layout:` には、この一覧の型の名前だけを書く。運用時は固定で、スライドごとに型を足したり変えたりしない。合う型がなければ近い型で代替し、どのスライドをなぜ代替したかを人間に報告する（図は `diagram-catalog.md` の冒頭のとおり、無理に当てはめず `canvas` で描く）。

- 寸法の単位は px。スライドは 1280×720。名前の付いた値（`slide-x` など）は `theme.css` のトークン。
- 文字数の上限は、文字の大きさと置ける幅から計算した値に1字の余裕をみたもの。数え方と型ごとの上限は `node .claude/skills/html-build/scripts/schema.mjs` が出す（正は `html-build/scripts/spec.mjs`）。最後はビルド時の検査で、実際の行数をブラウザで測って判定する。
- 図・表・グラフ・流れの中身は `diagram-catalog.md` の型を使う。この一覧は、スライドの枠（どこに何を置くか）だけを決める。

## 1. すべての型に共通すること

| 要素 | 決まり |
|---|---|
| 余白 | 左右 `slide-x`（54）、タイトルの上端 `slide-top`（63）、下端 `slide-bottom`（27） |
| タイトル | 左上。`text-title`（36px）・太字・`primary`。前に縦長の帯（幅 8px、高さは文字の 1.25 倍、タイトルとの間 24px、帯と文字の中心を揃える）。**1行のみ** |
| パンくず（任意） | 書かなければ「CHAPTER 01: 章の名前」の形で自動で入る。タイトルの上に、所属する章の名前を `text-breadcrumb`（16px）・太字・`primary` で書く |
| 説明文（lead） | 本文のある型（表紙・目次・章の扉・締め以外）では、タイトルの下 32 の位置に固定で置く。`text-body`（16px）・`ink`。幅は決まった幅（字数の目安の上限が3行に収まる幅）を基本にし、3行を超える長さなら、3行に収まるまで本文の幅いっぱいまで広げる。それでも3行を超える長さは書式チェックのエラー。目安より短いと注意（字数は `schema.mjs` の「共通」）。**必須**で、説明文の要らないスライドだけ `lead: false` と書いて外す |
| 本文の開始位置 | 説明文の下 32。説明文がないときはタイトルの下 `title-gap`（50） |
| 出典・図の番号 | 左下に `text-caption`（12px）・`label` の色で書く |
| ページ番号 | 右下に「n / N」。base.html が自動で付ける。表紙（`title`）には付けないが、数えるときは表紙も1枚と数える |
| 発表者ノート | `notes:` に書く。スライドには出ない |
| 太字 | 特に伝えたい語句を `**語句**` で囲む。数の目安は `schema.mjs` の「共通」（考え方は `html-build/components.md` 4.2） |
| 図の数 | 1枚に2つまで。3つ以上は検査で報告し、人間が確認する（`components.md` 4章） |
| 囲みの枠線 | 囲み（`two-column`・`do-dont`・`grid-4` の囲み、表、自由図のカード）には、枠線を付けるのが既定。線は自由図の箱と同じ（`components/_util.mjs` の `LINE`、2px）。枠線のない囲みは例外で、自由図の `area` の `soft` などの面だけを使う |

## 2. 型の一覧

書ける項目（必須・任意）と、文字数・項目数の上限は、この一覧には書き写さない。`node .claude/skills/html-build/scripts/schema.mjs [型の名前]` で出す（正は `html-build/scripts/spec.mjs`）。

| 型の名前 | 用途 | 見た目 |
|---|---|---|
| `title` | 表紙 | 下の 3.1 |
| `toc` | 目次 | 項目は書かない。後ろの `section` の title から自動で作る。6章までは1列、7章以上は2列（1列目を埋めてから2列目へ） |
| `section` | 章の扉 | 下の 3.2 |
| `title-body` | 文章中心 | 箇条書き。各項目は2行までに収める。文字は1段目 `text-lead`（18px）、2段目 `text-body`（16px）。下の 3.3 |
| `text-diagram` | 左に文章・右に図 | 文章の列は幅 `column`（560）。図は右に置く。箇条書きの文字は1段目 `text-body`（16px）、2段目 `text-sub`（14px）。下の 3.3 |
| `title-diagram` | 図が中心 | 図はタイトルと説明文の下の残りの高さいっぱい（画面の約 70%）。`diagrams` なら左右に2つ |
| `two-column` | 2つを比べる | 左右に小見出しと箇条書き。左は灰色、右は淡い青の地 |
| `do-dont` | 良い例と悪い例 | `do` は上端に `success` の帯、`dont` は上端に `error` の帯。緑と赤はこの型だけで使う |
| `grid-4` | 原則や要点を4つ並べる | 2×2。図の `cards`（4枚・2列・番号の丸）で描く。各項目は番号・小見出し・説明（3行まで）。番号の代わりにアイコン（`icon: phosphor:<名前>`、または `assets` の SVG）も置ける。4つちょうどでないときや、重さの違いを色で示したいときは `title-diagram` に `cards` を置く |
| `checklist` | 確認する項目の一覧 | 2列。済みは青の塗りとチェック、未済みは空の枠と太字（形でも区別する） |
| `closing` | 締め | 表紙と同じく白地＋下端の横の帯（表紙に合わせる）。「ありがとうございました」。問い合わせ先とメールは、ヒアリングで聞いた `brief.md` の `contact` から写す。なければ書かず、お礼だけを縦の中央に置く |
| `credits` | ライセンス表記 | license-notice のスクリプトだけが作る。outline.md には書かない |

## 3. 表紙と章の扉

背景は白。章の扉は左端に `primary` の縦の帯（幅 `strip`＝20）、表紙と締めは下端に横の帯（3.1）。全面を濃い青にしない（青の面積が大きいと見づらいため）。

### 3.1 表紙（`title`）

下端に横の帯を置く。章の扉（左端の縦の帯）と形を変え、一目で区別できるようにする。

| 枠 | 書き方 |
|---|---|
| title | `text-cover`（48px）・太字・`primary` |
| subtitle | `text-heading`（20px）・`ink` |
| date | **必須**。右下に `text-body`（16px）・`label` |
| author.org | 所属。左下に `text-body`（16px）・`label`（日付と同じ） |
| author.name | 氏名。所属と同じ `text-body`（16px）・`label`。太字にしない |

- 下端に横の帯（`primary`、高さ `strip`＝20）を引く。左端の縦の帯は使わない。
- title と subtitle をひとまとまりにし、左揃え（x=80）で縦の中央に揃える。文字の見た目の中心を合わせるため、0.04 文字分だけ上にずらす（Noto Sans JP での実測）。title と subtitle の間は 16。
- 日付と発表者は、帯の上（下端から 60）に置き、上に罫線（1px、`line`）を引いて区切る。発表者は左、日付は右。
- **日付と発表者は、ヒアリングで聞いた `brief.md` の `date`・`author` から写す**。日付は必須。発表者は次のどれでもよい。
  - 所属と氏名：2行で書く（上に所属、下に氏名）
  - 氏名のみ／所属のみ：1行
  - なし：日付だけを右に置く

### 3.2 章の扉（`section`）

左に章の番号・タイトル・説明、右にその章のトピックを置く。

| 枠 | 書き方 |
|---|---|
| 章番号 | 「CHAPTER 01」の形（2桁）。`text-heading`（20px）・太字・`blue-600`。**自動で付ける**（outline.md には書かない） |
| 進み具合 | 章番号の右に、章の数だけ小さな点（8px）を並べ、今の章を `primary`、ほかを `gray-200` で塗る。**自動で付ける**。章が増えても潰れない |
| title | `text-section`（64px）・太字・`primary`。2行まで（表紙の title と同じく `title: \|` に続けて字下げして書き、改行したところで改行する）。目次とパンくずでは1行にまとめる |
| description | その章で話すことの説明。`text-body`（16px）・`ink` |
| topics | 右の列（幅 400）。書かなければ右の列を作らず、左を横いっぱいに使う。見出し「トピック」（`text-body`・太字・`label`）と番号付きの一覧（`text-body`・`ink`）。左に細い線（2px、`line`） |

- 左右の列をそれぞれ縦の中央に揃える。「この章のゴール」の枠は使わない。
- 章の扉をどこに入れるかは、枚数で固定せず、構成（outline.md）を作るときに内容に合わせて決める。

### 3.3 箇条書き（`title-body`・`text-diagram` の `body`）

| 項目 | 決まり |
|---|---|
| 1段目 | 青の丸（10px）。`numbered: true` なら「1.」「2.」…の番号（青・太字）にする |
| 2段目 | 項目のすぐ後ろに文字の並びを書くと、その項目の下の段になる。白丸（10px、青の縁）。1つの項目の下に4つまで。3段目は書けない |
| 文字の大きさ | 段ごとに1段ずつ小さくする。`title-body` は 18px・16px（`text-lead`・`text-body`）、`text-diagram` は 16px・14px（`text-body`・`text-sub`） |
| 数 | 項目の数の上限と下限は1段目だけを数える |

```yaml
- numbered: true
- body:
    - 1段目の項目
    - [2段目の項目, 2段目の項目]
    - 次の1段目の項目
```

## 4. 型を選ぶ目安

- 結論や主張を言葉で伝える → `title-body`
- 図・グラフ・表を見せる → 説明が要るなら `text-diagram`、図だけで伝わるなら `title-diagram`
- A と B を比べる → `two-column`。正しい・誤りの対比なら `do-dont`
- 同じ重さの要点が4つ → `grid-4`（3つや5つ、6つなら `title-diagram` に図の `cards`）
- 章の扉（`section`）と目次（`toc`）を入れるかと、その位置は、枚数で固定しない。構成を作るときに内容に合わせて決め、構成の確認（承認ゲート）で人間が見る
