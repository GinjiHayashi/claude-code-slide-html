推測・独自に整理した範囲（草案のまま）：既存の手法どうしの組み合わせ方は、特定の出典によらない独自の設計。具体的には次のとおり。

- SCQA で答えを予告し、本文を基礎から積み上げる方針
- ストーリーの4つの要件 S1〜S4
- 前方参照の例外の決まり
- 同じ層の中の並べ方の基準1・2
- 順序とストーリーがぶつかったときの優先順位
- MoSCoW による優先度と格上げの決まり、抽象度を付けること
- 知識の呪いへの対策の「過半数」の基準
- ADEPT を使う対象・最低限の線・類推の限界を書くこと
